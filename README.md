# Monty Interpreter

## Description
Monty is an interpreter for Monty ByteCode files.

Opcodes Implemented
Opcode	Description
push	Pushes integer to stack
pall	Prints all values
pint	Prints top value
pop	Removes top element
swap	Swaps top two elements
add	Adds top two elements
nop	Does nothing
div	Divides second by top
mul	Multiplies top two
